# Busnes-tg-perepiski

Бот для **Telegram Business**, который сохраняет вашу переписку и присылает вам
копию сообщения, когда его **удаляют** или **изменяют** в ваших чатах —
«анти-удаление» для собственного аккаунта.

> ⚠️ **Важно и честно.** Бот работает **только с тем аккаунтом, который сам его
> подключил** через Telegram Business, и обрабатывает **вашу собственную
> переписку** (сообщения, которые вы получили или отправили). Это возможности
> официального Telegram Bot API (Business, с версии 7.2). Следить за чужим
> аккаунтом, который бота не подключал, через этот API **нельзя**. Вы отвечаете
> за соблюдение законов вашей страны о записи переписки и об уведомлении
> собеседников.

## Что умеет

- 🗑 **Удалённые сообщения.** Когда кто-то (собеседник или вы) удаляет сообщение
  в вашем чате, бот присылает вам сохранённую копию: текст и медиа (фото, видео,
  голосовые, кружки, документы, стикеры и т. д.).
- ✏️ **Изменённые сообщения.** Показывает, что было и что стало.
- 📥 **Все чаты сразу.** При подключении вы выбираете «Все чаты» — бот
  автоматически охватывает всю переписку, не нужно настраивать каждый диалог.
- 🔒 **Плашка только у вас.** Все уведомления приходят в личный чат с ботом —
  их видите только вы.
- 🔍 **Поиск** по сохранённой переписке: `/search текст`.
- 📦 **Экспорт** всей переписки в HTML-файл: `/export`. Фото, видео, голосовые,
  кружки и аудио **встраиваются в файл** — их можно смотреть и слушать прямо в
  браузере (лимит объёма — `EXPORT_MEDIA_MB`, по умолчанию 25 МБ).
- 🗂 **Архивный канал.** Можно дублировать удалённые/изменённые сообщения в
  отдельный канал или группу (переменная `ARCHIVE_CHAT_ID`).
- ↪️ **Источник пересылки.** У пересланных сообщений сохраняется и показывается,
  откуда они пришли («переслано от X») — в уведомлениях об удалении и в экспорте.

## Требования

- **Telegram Premium** (без него раздел Telegram Business недоступен).
- Бот, созданный у [@BotFather](https://t.me/BotFather) (нужен его токен).
- Python 3.11+ (или Docker).

## Установка и запуск

### 1. Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → задайте имя и username.
2. Скопируйте **токен**.

### 2. Настройте проект

```bash
git clone <этот-репозиторий>
cd Busnes-tg-perepiski

cp .env.example .env
# впишите в .env ваш BOT_TOKEN
```

### 3. Запуск

**Вариант А — локально:**

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m app.bot
```

**Вариант Б — Docker:**

```bash
docker compose up -d --build
docker compose logs -f
```

**Вариант В — VPS в один скрипт (Debian/Ubuntu, systemd):**

На свежем сервере (Ubuntu 22.04/24.04 или Debian 12) выполните по порядку:

```bash
# 1. Подключитесь к серверу по SSH
ssh root@IP_ВАШЕГО_СЕРВЕРА

# 2. Поставьте git (если нет) и склонируйте проект
apt-get update && apt-get install -y git
git clone https://github.com/gytfel/Busnes-tg-perepiski.git
cd Busnes-tg-perepiski

# 3. Запустите установщик — он поставит зависимости, спросит токен
#    и настроит автозапуск (systemd)
sudo bash install.sh
```

Скрипт `install.sh`:

- установит `python3`, `venv`, `pip`, `git`;
- создаст виртуальное окружение и поставит зависимости;
- спросит `BOT_TOKEN` (и по желанию `ARCHIVE_CHAT_ID`) и запишет `.env`;
- создаст systemd-сервис `busnes-tg-perepiski` и запустит его;
- включит автозапуск при перезагрузке сервера.

Управление сервисом после установки:

```bash
journalctl -u busnes-tg-perepiski -f      # смотреть логи в реальном времени
systemctl status busnes-tg-perepiski      # статус
systemctl restart busnes-tg-perepiski     # перезапуск (после правки .env)
systemctl stop busnes-tg-perepiski        # остановить
```

> Повторный запуск `install.sh` не затирает существующий `.env` — чтобы
> поменять токен или добавить архивный канал, отредактируйте `.env` вручную
> (`nano .env`) и выполните `systemctl restart busnes-tg-perepiski`.

### 4. Подключите бота к Telegram Business

1. В Telegram: **Настройки → Telegram Business → Чат-боты** (Settings →
   Telegram Business → Chatbots).
2. Впишите **username вашего бота**.
3. В разделе доступа выберите **«Все чаты»** (All chats), чтобы охватить всю
   переписку сразу. При желании можно исключить отдельные чаты.
4. Готово — бот пришлёт вам подтверждение в личку.

После этого откройте личный чат с ботом и отправьте `/start`, чтобы убедиться,
что он отвечает, и `/status` — чтобы увидеть статус подключения.

## Интерфейс (кнопки)

Управление — кнопками на постоянной клавиатуре снизу (команды тоже работают
как запасной вариант):

| Кнопка        | Команда            | Описание                                          |
|---------------|--------------------|---------------------------------------------------|
| 📊 Статус     | `/status`          | Подключения и число сохранённых сообщений         |
| 🔍 Поиск      | `/search <текст>`  | Нажмите и введите слово — поиск по переписке       |
| 📦 Экспорт    | `/export`          | HTML-файл со встроенными фото/видео/голосовыми      |
| 🧹 Экспорт и очистка | `/export_clear` | Выгрузить файл и **стереть** сохранённое с сервера |
| ℹ️ Помощь     | `/help`            | Короткая справка                                   |

> 🧹 **Очистка** полностью стирает базу — **все сообщения и запись о подключении** —
> и сжимает файл (`VACUUM`). Удаление происходит **только после успешной отправки
> файла**: если файл не ушёл, данные остаются. Медиафайлы на сервере не хранятся
> (бот держит только текст и ссылки `file_id`; сами файлы — в Telegram), так что
> после очистки на сервере не остаётся ничего. Подключение бот **восстанавливает
> сам** (`getBusinessConnection`) при следующем событии, так что переписка
> продолжит сохраняться без повторного подключения. Чтобы полностью чистить базу
> после *каждого* обычного экспорта, поставьте `PURGE_AFTER_EXPORT=true` в `.env`.

Откройте личный чат с ботом и нажмите **/start** — появится клавиатура с кнопками.

## Архивный канал (необязательно)

Чтобы удалённые и изменённые сообщения дублировались в отдельный канал/группу:

1. Создайте канал или группу, добавьте туда бота (в канал — **администратором**).
2. Узнайте ID чата (например, через [@getidsbot](https://t.me/getidsbot)); у
   каналов он начинается с `-100`.
3. Впишите его в `.env`: `ARCHIVE_CHAT_ID=-1001234567890` и перезапустите бота.

## Переменные окружения (`.env`)

| Переменная             | Обязательна | Описание                                                            |
|------------------------|:-----------:|---------------------------------------------------------------------|
| `BOT_TOKEN`            | да          | Токен бота от @BotFather                                             |
| `OWNER_ID`             | нет         | Явный ID владельца; по умолчанию — тот, кто подключил бота           |
| `DB_PATH`              | нет         | Путь к файлу SQLite (по умолчанию `messages.db`)                     |
| `NOTIFY_OWN_DELETIONS` | нет         | Уведомлять о сообщениях, которые вы удалили сами (`true`/`false`)    |

## Как это устроено

- Бот подписан на бизнес-апдейты Telegram: `business_connection`,
  `business_message`, `edited_business_message`, `deleted_business_messages`.
- Каждое проходящее сообщение сохраняется в SQLite (`app/database.py`): текст,
  тип и `file_id` медиа, автор, чат, время.
- На `deleted_business_messages` бот находит сохранённые копии по `chat_id` +
  `message_id` и пересылает их вам.
- На `edited_business_message` показывает старую версию из базы и новую из апдейта.

```
app/
├── bot.py            # запуск, long polling
├── config.py         # чтение .env
├── database.py       # SQLite-хранилище
├── utils.py          # извлечение медиа и доставка уведомлений
└── handlers/
    ├── business.py   # бизнес-подключение и сообщения (ядро)
    └── commands.py   # /start, /status, /help
```

## Ограничения

- Нужен **Telegram Premium** у владельца.
- Бот видит сообщения только **с момента запуска** — то, что пришло раньше,
  он не сможет восстановить (о таких удалениях придёт пометка без копии).
- Некоторые медиа с самоуничтожением могут не пересылаться по `file_id`.
- Это личный инструмент для вашего аккаунта; не используйте его для слежки за
  людьми без их ведома, если это запрещено законом.
